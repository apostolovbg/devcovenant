# DevCovenant Docs

## Overview
This folder holds the detailed docs for DevCovenant.
`README.md` is the starting point.
These pages explain the commands, config, profiles, policies, workflow, and the
main internal structure.

## Doc Set
The main reference set is:
- `installation.md` for install, deploy, upgrade, clean, undeploy, and
  uninstall
- `workflow.md` for the gate sequence, command order, logs, and recovery
- `config.md` for config review and ownership
- `profiles.md` for profiles, assets, translators, and workflow runs
- `policies.md` for policy descriptors, checks, runtime actions, and policy
  commands
- `refresh.md` for refresh behavior and managed-doc ownership
- `architecture.md` for the internal module layout
- `registry.md` for tracked registry and local workflow state
- `troubleshooting.md` for common failures and recovery

## Working Rules
Keep these docs concrete.
Use direct language, short paragraphs, and examples that help the reader do the
work.
Avoid meta-commentary and avoid stuffing every page with terms that only mirror
internal code names.
